# PumAgent 🤖 나만의 완벽한 인공지능 비서

**여러분이 말을 걸 때까지 가만히 대기만 하는 챗봇은 이제 그만!** 

만약 내 PC에 살고 있는 AI가 아침에 스스로 깨어나 뉴스를 찾아보고, 내가 3주 전에 무심코 던진 관심사를 완벽하게 기억하며, 심지어 백그라운드 환경에서 작업을 하다가 중요한 이슈가 터지면 내 스마트폰 텔레그램으로 먼저 카톡을 보내듯 알림을 쏴준다면 어떨까요?

**PumAgent**를 소개합니다. 단순한 챗봇이 아닙니다. 이 앱은 당신의 윈도우/맥 데스크톱에서 숨 쉬고 살아가는 **진정한 의미의 '자율 행동형(Autonomous) AI 에이전트'** 입니다.

---

## ✨ 왜 PumAgent 인가요? (주요 매력 포인트)

- **🧠 절대 잊지 않는 완벽한 기억력 (장기 메모리 브레인)**
  PumAgent는 자체 개발한 초고속 데이터베이스 `DBX-Core`를 기반으로 한 '브레인'을 가지고 있습니다. 한 번 알려준 취향이나 규칙은 영원히 기억합니다. 똑같은 말을 여러 번 반복할 필요가 없습니다!

- **⏰ 내가 잠든 사이에도 돌아가는 자동화 (백그라운드 스케줄러)**
  한 시간마다 비트코인 시세를 체크하고 싶다고요? 스케줄을 던져주기만 하세요! 목표를 이해하고, 스스로 추론하여 능동적으로 행동하는 (Goal-Reason-Action) 루프가 내 PC 백그라운드에서 24시간 철야로 돌아갑니다.

- **📱 먼저 말을 걸어오는 AI (선제적 텔레그램 연동)**
  계속 앱을 켜서 확인할 필요가 없습니다! 당신의 텔레그램과 연동해 두면, Agent가 자율 작업을 수행하다 결정적인 정보를 발견했을 때 즉각 모바일 화면 위로 푸시 알림을 쏴줍니다. 진짜 개인비서를 고용한 것 같은 경험을 해보세요.

- **🕷️ 끝을 보는 집요한 정보 검색 시스템**
  구글 검색 API 한도가 초과되었다구요? 걱정 마세요. PumAgent는 스스로 판단하여 DuckDuckGo 및 Yahoo 브라우저 크롤링 시스템으로 자동 우회전환하여 당신이 원하는 정보를 기어코 찾아냅니다.

- **🪄 어떤 프로그램도 설치할 필요 없는 마법의 '코드 자동 생성'**
  초경량 `Rhai` 스크립트 엔진이 몸체에 완전히 내장되어 있습니다! AI가 새로운 API와 통신하고 싶을 때 Python이나 복잡한 파워쉘 코드를 설치할 필요 없이, 즉석에서 안전한 플러그인(스크립트)을 뚝딱 만들어 내고 스스로 실행까지 해냅니다. 

- **⚡ 깃털 같이 가볍고 번개처럼 빠른 속도**
  무거운 일렉트론(Electron)은 버렸습니다. **Rust 언어와 Tauri 엔진**을 사용하여 타 데스크톱 앱 대비 메모리(RAM)를 획기적으로 적게 먹습니다. Windows, macOS, Linux 어디서든 네이티브 앱처럼 부드럽고 가볍게 작동합니다.

## 🛠️ 백엔드 기술 스택 (The Geeky Stuff)

우리는 압도적 퍼포먼스와 안정성을 위해 최고의 무기들만 골랐습니다:
1. **프론트엔드**: Svelte 5 + Vite + TypeScript (극강의 반응형 UI 선사)
2. **백엔드 심장**: Rust + Tauri (안전하고 타협 없는 네이티브 처리 속도)
3. **독자 데이터베이스**: `DBX-Core` (Zero-Latency를 지향하는 Key-Value 스토리지)
4. **AI 모델 연동**: 사생활 보호를 위한 로컬 모델(Ollama) 부터 가장 똑똑한 외부 API (OpenAI, Gemini) 지원

## 🚀 비서 채용하기 (시작 가이드)

준비되셨나요? 나만의 비서 에이전트를 데스크톱에 고용하기 위해선 다음 도구들만 있으면 됩니다.

### 사전 요구 사항
- Node.js (v18 다운로드)
- Rust & Cargo (1.77.2+)
- Visual Studio / C++ Build Tools (Windows 네이티브 모듈 빌드 환경)

### 설치 방법
1. 프로젝트를 당신의 컴퓨터로 가져옵니다.
   ```bash
   git clone https://github.com/bytelogiccore-spec/pumAgent.git
   cd pumAgent
   ```
2. 프론트엔드 종속성을 설치합니다.
   ```bash
   npm install
   ```
3. 개발 모드로 애플리케이션을 구동하여 비서를 깨웁니다.
   ```bash
   npm run tauri dev
   ```

### 프로덕션 빌드 (설치 파일 만들기)
친구에게 공유할 수 있는 설치 파일(exe/dmg)을 직접 뽑아내고 싶다면 다음 명령어를 실행하세요:
```bash
npm run tauri build
```
바텐이 끝나면 `src-tauri/target/release/bundle` 폴더 안에 따끈따끈한 설치 파일이 완성되어 있을 것입니다!
